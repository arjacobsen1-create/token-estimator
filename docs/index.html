Token Estimator

Built by Anahita Jacobsen · Live demo

Paste a context and a question. The estimator counts the tokens, shows where they sit, predicts what the reply will cost, and prices the task on every model, at your volume. It runs entirely in your browser, on the same engine as the code in this repo (src/token-core.js, inlined into this page). Prices are editable defaults in the code, verify them against the provider before relying on a figure.

On a flat subscription the marginal cost per run is $0, the plan is already paid; these dollars are API-equivalent, real charges for pay-per-token users. Either way the tokens are real: they burn allowance, limits and context window.

SAP & Transformation edition

The domain edition: 21 shapes of SAP work (Run, Build, Transform), each with a typical input size, guidance, and the protection to apply before pasting anything into a model. Built from public SAP work shapes only. The full list is SAP-TASKS.md in the repo.

Full code, lesson notes and a runnable proof (node test/smoke.js, 4 checks) are in the repository. Counting is a calibrated heuristic; the production step is each model's real tokenizer, a one-function swap by design.

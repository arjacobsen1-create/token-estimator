On a flat subscription the marginal cost per run is $0, the plan is already paid; these dollars are API-equivalent, real charges for pay-per-token users. Either way the tokens are real: they burn allowance, limits and context window.

The minimised text is the same for every model. The model only changes the token counter and the prices.
